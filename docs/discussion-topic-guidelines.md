# 토의·토론 주제 편성 지침

트루핑키스 리터러시의 토의·토론 주제는 어린이가 실제 사회 쟁점을 읽고, 근거를 비교하고, 자기 기준을 세우도록 돕기 위해 편성한다.

## 화면 구조

- 큰 주제: 다루는 분야와 문제를 알려주는 넓은 이름이다.
- 토의 질문: 실제 활동에서 의견과 근거를 모을 중심 질문이다. 하나의 큰 주제 안에 여러 질문을 둘 수 있으며, 교사는 수업 목표와 학급 수준에 맞는 질문을 골라 진행한다.
- 생각해 볼 관점: 토의 질문에 답하기 전 기준, 조건, 책임, 예외를 따져 보는 보조 질문이다.

## 주제 유형

### 찬반 토론형

실제 논쟁이 있고 입장이 비교적 분명하게 갈리는 주제에 사용한다.

좋은 예:

- 학교에서 스마트폰 사용을 강하게 제한해야 할까?
- 기후 대응을 더 빠르게 추진해야 할까, 단계적으로 추진해야 할까?
- 플라스틱 규제를 개인 실천보다 먼저 강화해야 할까?

주의할 점:

- 이미 사실로 확인된 내용을 찬반으로 만들지 않는다.
- 과학적 사실 자체를 찬반 논쟁처럼 만들지 않는다.
- 찬성과 반대가 모두 주장 가능한 정책 선택, 우선순위, 규칙 문제를 다룬다.

### 해결 설계형 토의

사회적으로 필요성이 크거나 이미 도입이 진행 중인 주제에서 방법, 기준, 조건, 책임을 정할 때 사용한다.

좋은 예:

- 학교에서 AI 도움을 어떤 활동에는 허용하고 어떤 활동에는 제한해야 할까?
- 교육 지원은 누구에게 어떤 기준으로 제공해야 할까?
- 문화 자료 공개와 보호 기준은 어떻게 정해야 할까?

주의할 점:

- 억지로 찬반 구도를 만들지 않는다.
- “해야 할까 말까”보다 “어떻게 할까”, “어디까지 허용할까”, “누가 책임질까”를 묻는다.
- 어린이가 기준을 세워 볼 수 있도록 선택, 기준, 조건, 책임 중 하나 이상을 포함한다.

## 토의 질문 작성 기준

토의 질문은 반드시 아래 요소 중 하나 이상을 포함한다.

- 선택: A와 B 중 무엇을 우선할지 묻는다.
- 기준: 어떤 기준으로 판단할지 묻는다.
- 조건: 어떤 경우에 허용하거나 제한할지 묻는다.
- 책임: 누가 무엇을 맡아야 하는지 묻는다.

한 큰 주제에 여러 토의 질문을 둘 때:

- 질문끼리는 같은 말을 반복하지 않고 서로 다른 선택, 기준, 조건, 책임을 다룬다.
- 첫 번째 질문은 대표 질문으로 두고 `essentialQuestion`에도 같은 문장을 넣는다.
- 나머지 질문은 수업에서 선택할 수 있는 대안 질문으로 쓰되, 생각해 볼 관점보다 크고 중심적인 질문이어야 한다.
- 각 질문은 한 차시 안에 근거를 비교할 수 있을 만큼 범위를 좁힌다.

초등학교 고학년용 문구를 함께 둘 때:

- 기존 큰 주제, 토의 질문, 생각해 볼 관점은 유지하고 `elementaryTitle`, `elementarySummary`, `elementaryDiscussionQuestions`, `elementaryDiscussionFrame`, `elementaryWritingPrompt`를 별도로 둔다.
- 초등 고학년용 질문도 선택, 기준, 조건, 책임 중 하나 이상을 포함해야 한다.
- 쉬운 말로 바꾸되 쟁점의 핵심 판단은 약하게 만들지 않는다.
- `elementaryDiscussionQuestions`와 `elementaryDiscussionFrame`은 기존 질문·관점과 같은 개수를 유지해 자료의 `relatedQuestions` 번호가 그대로 통하도록 한다.

피해야 할 질문:

- 정답이 이미 정해진 사실 확인 질문
- “좋을까요?”처럼 방향만 묻고 판단 기준이 없는 질문
- 너무 넓어서 한 차시 안에 근거를 비교하기 어려운 질문
- 어린이에게 책임을 과하게 떠넘기는 질문

## 실제 대회 논제 참고 기준

- 세계·국내 토론대회 논제는 주제가 실제로 토론될 만한지 점검하는 참고 자료로 쓴다.
- 대회 논제를 그대로 복사해 앱의 중심 질문으로 쓰지 않고, 초등·중등 수업에서 근거를 읽고 판단할 수 있도록 선택, 기준, 조건, 책임 질문으로 재구성한다.
- `competitionReferences`에는 대회명, 연도, 출처 URL, 원 논제, 수업용 변환 이유, 연결되는 토의 질문 번호를 남긴다.
- 대회가 공개한 읽기 자료, 논제 참고자료, 주제도서 안내가 있으면 `competitionReferences.readingMaterials`에 제목, 출처, 링크, 자료 성격, 사용 메모, 저작권 메모를 남긴다.
- 대회 읽기 자료가 책, 유료 자료, 저작권 보호 자료라면 본문·번역·요약을 앱에 옮기지 않고 링크와 최소 설명만 제공한다.
- 외부 읽기 자료를 본문으로 재사용할 수 없지만 수업 전 이해 자료가 필요하면 `classroomReadingMaterials`에 사이트 자체 창작 읽기 자료를 둔다.
- `classroomReadingMaterials`는 외부 기사·대회 자료를 번역하거나 요약하지 않고 새 문장으로 작성하며, `copyrightNote`에 창작 자료임을 분명히 적는다.
- 같은 큰 주제 안에서도 대회 논제와 직접 연결되지 않는 질문은 억지로 대회형 찬반으로 바꾸지 않는다.
- 대회 논제가 너무 성인 중심이거나 초등 고학년에게 과도하게 어렵다면 참고만 하고, 앱에는 더 쉬운 정책 선택 질문으로 낮춰 쓴다.

## 생각해 볼 관점 작성 기준

생각해 볼 관점은 토의 질문보다 작고 구체적이어야 한다.

- 관점은 기본 3개 안팎으로 두되, 교사가 질문을 고르기 위해 더 많은 기준·조건·책임을 비교해야 하는 주제는 4~5개까지 둘 수 있다.
- 서로 다른 이해관계자나 기준을 보여준다.
- 자료를 읽고 근거를 찾을 수 있는 질문으로 쓴다.
- 관점 중 하나가 더 좋은 토의 질문이라면 토의 질문으로 올린다.

## 근거자료 편성 기준

- 가능한 한 서로 다른 입장이나 관점을 함께 둔다.
- 모든 근거자료는 `readingFocus`로 학생이 읽을 때 확인할 점을 적고, `relatedQuestions`로 어떤 토의 질문에 특히 도움이 되는지 연결한다.
- 초등 고학년 보기에서 자료를 더 쉽게 읽게 하려면 `elementaryReadingFocus`에 더 짧고 쉬운 읽기 초점을 적는다.
- 통계, 표, 조사, 연구, 논문은 `resourceKind`로 자료 성격을 표시한다.
- 통계, 조사, 연구, 논문처럼 근거로 직접 쓰기 쉬운 자료는 `evidenceInfo`에 출처·자료 성격, 조사대상·범위, 시점, 주의해서 볼 점을 적는다.
- CC BY, CC0, 공공누리 제1유형, OGL, 미국 연방정부 공개 자료처럼 재사용 조건이 명확하고 원자료 CSV/API를 확인할 수 있는 경우에는 `embeddedEvidence`로 작은 표를 재생산할 수 있다.
- `embeddedEvidence`에는 원자료 링크, 라이선스, 단위, 발췌 기준, 반올림·단위 변환 같은 재생산 방법을 반드시 적는다. 두 개 이상의 원자료를 조합하면 `sourceUrls`에 각각의 원자료 링크를 적는다.
- 재생산 표에는 `auditKey`, `verificationNote`, `copyrightBasis`를 두고 `scripts/audit-embedded-evidence.mjs`로 원자료 값과 표시값을 대조한다.
- 감사 스크립트는 일괄 통과만 확인하지 않고 재생산 항목마다 제목, 단위, 열, 원자료 링크, 행 값을 별도 케이스로 검산해야 한다. 새 `embeddedEvidence`를 추가하면 같은 커밋에서 전용 감사 케이스도 추가한다.
- 원자료와 표시값이 맞지 않거나, 라이선스·재사용 조건을 확인할 수 없거나, 자동 대조가 어려운 복잡한 그래프는 폐기하고 외부 원문 링크 카드만 남긴다.
- 번역·어린이용 재구성이 가능한 핵심 자료는 외부 원문 카드만 두지 말고 `news-*.json` 내부 읽기 글로 작성해 학생이 사이트 안에서 먼저 이해할 수 있게 한다.
- 별도 기사로 만들기 전이라도 재사용 조건이 명확한 외부 원문은 `koreanReconstruction`과 `elementaryKoreanReconstruction`으로 카드 안에 짧은 한국어 재구성 읽기 글을 둔다.
- 카드 안 재구성 글은 원문을 그대로 번역하지 않고, 토의 질문에 필요한 핵심 내용을 새 문장으로 풀어쓴다.
- 내부 읽기 글의 `sourceNote`에는 원문 제목, 원문 URL, 라이선스 또는 공개 근거, 재구성 방식, 원문 이미지·표를 그대로 쓰지 않았다는 점을 적는다.
- 내부 재구성 글과 외부 원문 카드 모두 `relatedQuestions`에 질문 번호를 연결한다.
- 본문 재구성은 공공누리 제1유형, CC BY, CC0 등 허용 조건이 명확한 자료에 한정한다.
- 저작권 확인이 어렵거나 자유 재사용이 아닌 자료는 본문을 옮기지 않고 제목, 출처, 최소 설명, 원문 링크만 제공한다.
- 외국 자료는 번역·재구성이 가능한 라이선스인지 먼저 확인한다.
- Britannica ProCon처럼 구조 참고에 유용하지만 저작권 보호 콘텐츠인 자료는 본문이나 번역문을 가져오지 않고 주제 설계 참고용으로만 사용한다.
